# Emulator-Survey-Data-2025

Anonymous survey answers about ROM emulators and how people use them, collected in 2025. Published on Zenodo as "Anonymous Emulator Survey Data 2025: Initial Release": https://doi.org/10.5281/zenodo.15663380

## Authors

Zeldano Shan Oeffie, Nur Aini Rakhmawati, Marvello Adipertama and Razza Ibrahmwibowo Muktiadi, as listed on the Zenodo record.

## The data

`Emulator-Survey-Data-2025.xlsx` holds 501 responses on its first sheet. The other two sheets are empty.

| Column | What's in it |
|---|---|
| No | Row number (only filled for the first two rows) |
| Initial | Initials only, no names |
| Country | Country name in Indonesian, 9 in total. 432 of the 501 answers are from Indonesia |
| Age | 16 to 30 |
| what is known about the ROMs emulators website | Coded 1 to 3 |
| used unofficial emulator | Coded 1 or 2 |
| Do you think that having a ROM emulator can be the main solution in playing games? | Coded 1 or 2 |
| Are you a user of legal or illegal games? | Coded 1 or 2 |

The file doesn't say what each code stands for.
